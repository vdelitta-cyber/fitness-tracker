Hoe stel ik dit in?
  1. Ga naar console.cloud.google.com en maak (of kies) een project.
  2. Enable de Google Sheets API en Google Drive API onder "APIs & Services".
  3. Ga naar "OAuth consent screen", kies "External", vul een app-naam in en voeg je eigen e-mailadres toe als test user.
  4. Ga naar "Credentials" → "Create Credentials" → "OAuth client ID" → type Web application.
  5. Voeg bij "Authorized JavaScript origins" toe:
  6. Kopieer de Client ID hierboven en klik Opslaan, daarna Verbind met Google.

Zonder Client ID werkt de tracker gewoon lokaal (localStorage) — sync is optioneel.
